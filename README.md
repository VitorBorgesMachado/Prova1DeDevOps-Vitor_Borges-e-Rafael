# Dashboard de Hábitos de Estudo

## Sobre o projeto

O **Dashboard de Hábitos de Estudo** é um projeto desenvolvido para
auxiliar no acompanhamento e organização da rotina de estudos.

O sistema é dividido em três áreas principais:

- **Metas:** permite acompanhar os seus objetivos de estudo e seu progresso em cada um deles.
- **Histórico:** apresenta o registro das atividades e sessões de estudo.
- **Insights:** apresenta informações sobre os hábitos e o desempenho nos estudos.

---

## Objetivo

O objetivo do projeto é oferecer uma visão simples e organizada da rotina
de estudos, permitindo acompanhar o progresso, consultar atividades
anteriores e identificar os padrões de estudo.
