O projeto utiliza uma variação do **GitHub Flow**.

O desenvolvimento de novas funcionalidades será realizado em branches específicas,
criadas a partir da branch `main`.

Após a conclusão da funcionalidade, será aberto um Pull Request para revisão e
posterior integração com a branch `main`.

### Fluxo

```text
main
 ├── feature/metas
 ├── feature/historico
 └── feature/insights

feature/* → Pull Request → revisão → main
